# 长夜守望

一款原创的"幸存者类"(bullet heaven)网页小游戏:提灯的守夜人在荒原上抵御夜兽,撑过 15 分钟等到黎明即胜利。

纯 HTML + Canvas + JavaScript,无构建、无依赖、无外部素材(图形为程序化绘制,音效为 WebAudio 合成)。

## 运行

直接用浏览器打开 `index.html` 即可;或者起一个静态服务器:

```bash
cd survivor-game
python3 -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765
```

## 操作

| 操作 | 键位 |
|------|------|
| 移动 | WASD / 方向键;触屏或鼠标按住拖动(虚拟摇杆) |
| 升级选卡 | 点击卡片,或按 1 / 2 / 3;R 重掷 |
| 暂停 | Esc / P |
| 静音 | M |

武器全部自动攻击,玩家只负责走位和拾取。

## 玩法

- **升级三选一**:击杀掉落经验宝石,升级后从武器/被动道具中选一项,最多 6 把武器 + 6 件被动。
- **武器进化**:武器升到满级且持有对应的被动道具后,升级选项里会出现金色的"进化"卡。

  | 武器 | 进化搭档 | 进化形态 |
  |------|----------|----------|
  | ✨ 星火弹 | ⏳ 急速沙漏 | 🌟 星爆 |
  | 🔆 环绕萤火 | 🔍 广域透镜 | 💫 永恒星环 |
  | ⚡ 落雷 | 🔮 复制棱镜 | 🌩️ 雷暴 |
  | 🌿 荆棘光环 | 🛡️ 铁木护符 | 🌵 荆棘壁垒 |
  | 🌀 回旋飞刃 | 👢 疾风靴 | 🌪️ 风暴之刃 |
  | ☄️ 陨星 | 💎 力量符石 | 🔥 天火 |
  | ❄️ 霜环 | 💧 晨露 | 🧊 凛冬 |
  | 🔱 光矛 | 🧲 引星磁石 | 🌠 引星矛 |

- **怪潮**:敌人种类、数量和血量随时间增长;每 45 秒出现一只精英(击杀掉宝箱),定时出现包围圈。
- **Boss**:4:00、8:00、12:00 各出现一只"夜魇"。它蓄力时地面会出现红色预警通道,横向离开通道即可躲开冲锋。
- **局外成长**:每局获得的金币可在主菜单购买永久强化、解锁新角色。存档保存在浏览器 localStorage。

## 代码结构

```
survivor-game/
├── index.html
├── style.css
└── js/
    ├── config.js    # 数据表:武器、被动、角色、敌人、波次、事件(调数值只改这里)
    ├── utils.js     # 工具函数、空间网格、存档
    ├── weapons.js   # 各类武器的行为
    ├── core.js      # 核心逻辑:刷怪、战斗、升级、结算(不依赖 DOM)
    ├── audio.js     # WebAudio 合成音效
    ├── render.js    # Canvas 渲染
    ├── ui.js        # 菜单 / 选卡 / 结算 / HUD
    └── main.js      # 输入与主循环
```

`core.js` 只通过 `Input` / `UI` / `Sfx` 三个全局对象与外界交互,可以在 Node 里用桩对象替换它们,快进跑完整局来验证改动或调数值。
