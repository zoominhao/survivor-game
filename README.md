# 长夜守望

一款原创的"幸存者类"(bullet heaven)网页小游戏:提灯的守夜人在荒原上抵御夜兽,撑过 15 分钟等到黎明即胜利。

纯 HTML + Canvas + JavaScript，无构建、无依赖。界面采用原创山水 SVG 和线刻图标，战斗图形、原创配乐和音效均实时生成。

## 运行

直接用浏览器打开 `index.html` 即可;或者起一个静态服务器:

```bash
cd survivor-game
python3 -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765
```

## 操作

| 操作 | 键位 |
|------|------|
| 移动 | WASD / 方向键;触屏或鼠标按住拖动(虚拟摇杆) |
| 升级选卡 | 点击卡片,或按 1 / 2 / 3;R 重掷 |
| 暂停 | Esc / P |
| 跳过角色开场 | 点击「跳过开场」，或按 Esc / Enter / 空格 |
| 静音（音乐和音效） | M / 右上角声音按钮 |

武器全部自动攻击,玩家只负责走位和拾取。
每局开战前会显示所选角色的「点灯入阵」立绘；开场期间不计入战斗时间。
配乐在首次点击或按键后播放；名册、战斗和夜魇有不同段落，暂停和切到后台时淡出。

## 玩法

- **升级三选一**:击杀掉落经验宝石,升级后从武器/被动道具中选一项,最多 6 把武器 + 6 件被动。
- **本局成长装饰**:完成 2、5、10 级的选卡后依次点亮头饰、围巾和脚下印纹。开心是金边耳机配青绿围巾，果果是粉花发夹配玫粉围巾。装饰不改变属性，重开时重置。
- **武器进化**:武器升到满级且持有对应的被动道具后,升级选项里会出现金色的"进化"卡。

  | 武器 | 进化搭档 | 进化形态 |
  |------|----------|----------|
  | 星火弹 | 急速沙漏 | 星爆 |
  | 环绕萤火 | 广域透镜 | 永恒星环 |
  | 落雷 | 复制棱镜 | 雷暴 |
  | 荆棘光环 | 铁木护符 | 荆棘壁垒 |
  | 回旋飞刃 | 疾风靴 | 风暴之刃 |
  | 陨星 | 力量符石 | 天火 |
  | 霜环 | 晨露 | 凛冬 |
  | 光矛 | 引星磁石 | 引星矛 |
  | 鼠伴出击（开心专属） | 疾风靴 | 百鼠夜行 |
  | 灵猴踏枝（果果专属） | 广域透镜 | 群猴闹山 |

- **怪潮**:敌人种类、数量和血量随时间增长;每 45 秒出现一只精英(击杀掉宝箱),定时出现包围圈。
- **荒原地形**:松树、竹丛和山石会挡住玩家及普通夜兽，幽魂和夜魇可穿越。走近石灯、火盆或纸灯笼会点亮它们，照亮周围的路，且本局内不会熄灭。受伤时每盏石灯还可回复一次生命（最多 12% 生命上限）；穿过芦苇会拨动草叶。投射物和拾取判定不受地形影响。
- **昼夜与天气**:从暮色松道入夜，途经起风的竹径、下雨的石庭和积雪山径，最后迎来黎明。景色渐变时不会移动或增加障碍；雨雪与风不会改变移速。系统开启「减少动态效果」时隐藏天气粒子和植物摆动。
- **Boss**:4:00、8:00、12:00 各出现一只"夜魇"。它蓄力时地面会出现红色预警通道,横向离开通道即可躲开冲锋。
- **局外成长**:每局获得的金币可在主菜单购买永久强化、解锁新角色。存档保存在浏览器 localStorage。
- **小老鼠·开心**:默认解锁，移速 +8%、生命 -10。专属武器「鼠伴出击」会自动派小鼠追击夜兽，升到 6 级并持有疾风靴后可进化为「百鼠夜行」。头像保留照片参考里的黑色耳机、黄衫和双手比耶，不包含原照片。
  - 战斗时手持小手电，暖光照向最近的移动方向。灯光只影响画面，不参与战斗判定。
  - 开心升级时优先出现尚未习得的专属武器：**黏黏年糕**留下踩中才触发的范围减速陷阱，**冰淇淋旋风**用绕身甜筒伤害并减速敌人，**彩糖连发**朝附近敌人射出彩色糖果。
  - **西瓜炸弹**抛向夜兽，落地造成范围伤害；**篮球投射**命中后弹向附近不同的夜兽，升级可增加弹射次数。
- **小啾咪·果果**:默认解锁，攻击数量 +1、生命 -10。专属武器「灵猴踏枝」会派小猴跃向夜兽，落地造成范围伤害。升到 6 级并持有广域透镜后可进化为「群猴闹山」。保留原有的熊猫卫衣造型。
  - 果果升级时优先出现尚未习得的专属技能：**土豆滚滚**朝移动方向滚出可贯穿并推开夜兽的土豆，**番茄飞溅**命中后留下持续伤害的番茄酱。
  - 保命技能 **芒果干补给** 在生命低于 85% 时自动回血；**试卷护盾** 挡住伤害并减速附近夜兽，升级后最多可储存两张试卷。
- **妈妈·霄霄**:默认解锁，生命 +10、护甲 +1。开局用 **香辣连发** 投出辣条，升级可选 **万马奔腾** 召唤冲锋小马、**妈妈怒吼** 震退周围夜兽、**水润护肤** 回血并短时间减伤。选人头像保留照片中的中分长发、羽绒服、红围巾和举手姿势，不包含原照片。

## 代码结构

```
survivor-game/
├── index.html
├── style.css
├── art/           # 原创山水封面与灯笼印章
└── js/
    ├── config.js    # 数据表:武器、被动、角色、敌人、波次、事件(调数值只改这里)
    ├── utils.js     # 工具函数、空间网格、存档
    ├── terrain.js   # 区块场景生成与实体碰撞
    ├── environment.js # 景色时间表和地形交互
    ├── weapons.js   # 各类武器的行为
    ├── core.js      # 核心逻辑:刷怪、战斗、升级、结算(不依赖 DOM)
    ├── audio.js     # WebAudio 分层音效与混音
    ├── music.js     # 原创配乐谱和音频排程
    ├── echo-figure.js # 开心的矢量头像和跑步造型
    ├── xiaoxiao-art.js # 霄霄的矢量造型与技能特效
    ├── food-art.js # 角色食物技能的战斗绘制
    ├── terrain-art.js # 松、石、灯等场景物件的贴图
    ├── environment-art.js # 地表过渡与雨、雪、风画面
    ├── wardrobe.js  # 本局成长装饰与等级规则
    ├── icons.js    # HUD、武器和道具的原创 SVG 图标
    ├── render.js    # Canvas 渲染
    ├── ui.js        # 菜单 / 选卡 / 结算 / HUD
    └── main.js      # 输入与主循环
```

`core.js` 只通过 `Input` / `UI` / `Sfx` 三个全局对象与外界交互,可以在 Node 里用桩对象替换它们,快进跑完整局来验证改动或调数值。
在项目目录运行 `node --test` 可验证音频切换、地形碰撞、角色开场、专属技能、进化规则和旧存档兼容。
