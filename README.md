# 长夜守望

一款原创的"幸存者类"(bullet heaven)网页小游戏:提灯的守夜人在荒原上抵御夜兽,撑过 15 分钟等到黎明即胜利。

纯 HTML + Canvas + JavaScript，无构建、无依赖。界面采用原创山水 SVG 和线刻图标；战斗图形、配乐和大部分音效实时生成，鬼新娘的人声随页面内置。

## 运行

直接用浏览器打开 `index.html` 即可;或者起一个静态服务器:

```bash
cd survivor-game
python3 -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765
```

### 双人守夜：好友或机器人

1. 两台设备连接同一个 Wi-Fi，都打开 [长夜守望](https://zoominhao.github.io/survivor-game/)，在名册选好角色，再点「双人守夜」。
2. 房主点「创建邀请」并复制邀请码；网页端也可复制**邀请链接**。朋友点开链接会填好邀请码，或在「加入朋友」里粘贴码或链接，再把生成的**应答码**复制回传。
3. 房主粘贴应答码并点「连接」。两人进房后，队友点「准备」，房主就能点「开始」。队友在开局前可取消准备。

这是浏览器之间的 WebRTC 直连：只用 GitHub Pages 托管页面，不接信令、STUN、TURN 或云服务器。需要网络允许设备互访；部分访客 Wi-Fi 会隔离设备。浏览器如询问本地网络访问，请允许。房主需保持页面开启；退出或断线后需重新换码，不支持接续旧局。

支持压缩的浏览器默认生成较短的 `I2-` 邀请码和 `A2-` 应答码。另一端不支持压缩时，房主可点「改用兼容码」。双方需要使用同一版本的游戏。仍需互发一次，不是六位数房间码。

GitHub Pages 不会自动搜索同一 Wi-Fi 上的设备。邀请生成约 45 秒后若没有好友入房，将以机器人补位；好友入房后不再倒计时。也可在大厅直接点「和机器人开局」，不联网。机器人会跟随、避开部分障碍与 Boss 预警、自动战斗和为自己选卡。真人与机器人都占同一个队友席位。

双人仍守十五分钟，使用相同地图和三位 Boss。两人各自走位和构筑、共享经验，真人轮流选卡，宝箱由拾取者获得。房主决定 Boss 战前抉择及全局暂停，来客打开本机菜单不会暂停队友。倒下后队友可在身边站稳 2 秒扶起（受击或移动中断，全队每局一次，复起后有约 25% 生命）；击败 Boss 仍可唤回倒下的队友。双人使用基础属性，不带入永久强化，不开作弊，不写单人金币或战绩。

## 操作

| 操作 | 键位 |
|------|------|
| 移动 | WASD / 方向键;触屏或鼠标按住拖动(虚拟摇杆) |
| 升级选卡 | 点击卡片,或按 1 / 2 / 3;R 重掷 |
| Boss 战前抉择 | 点击选项，或按 1（镇守）/ 2（悬赏）/ Esc（照常迎战） |
| 暂停 | Esc / P |
| 双人快捷信号 | Q / 右下角「信号」，展开后可点按或用 1–4 发送 |
| 跳过角色开场 | 点击「跳过开场」，或按 Esc / Enter / 空格 |
| 声音设置 | 扬声器按钮（主菜单、战斗右上或暂停面板） |
| 总静音 | M / 声音设置里的「总静音」 |
| 隐藏作弊面板 | 对局中 Shift + G，或 2.5 秒内连点倒计时 5 次 |

武器全部自动攻击,玩家只负责走位和拾取。
每局开战前会显示所选角色的「点灯入阵」立绘；开场期间不计入战斗时间。
音乐和音效各有 0–100% 音量滑杆，设置随存档保留；旧存档原有的总静音设置不变。松林、雨庭、雪岭的配乐不同；纸扎童子、僵尸合围或鬼新娘登场时会短暂切换段落，三位 Boss 各有主题。关键登场声仍会压低配乐和常规战斗声，把喊叫和预警留在前景。鬼怪音效与 Boss 配乐可在「作弊面板 → 声音测试」试听，试听不算作弊。鬼新娘人声以 [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) 的普通话输出为底，经变声与回声处理；游玩时不需要模型或网络。

作弊面板提供无敌开关、回满生命、本局金币和经验。仅打开面板不会影响记录；真正使用一项后，本局标为练习局，不计入正式战绩和金币奖励。重开即恢复正常。

## 玩法

- **升级三选一**:击杀掉落经验宝石,升级后从武器/被动道具中选一项,最多 6 把武器 + 6 件被动。
  - **AI 守夜军师**根据当前卡片、血量和装备给出一条本地建议，例如提醒进化所需道具或低血量时可选的回血卡。它不替玩家选，也不修改选项。
- **本局换装**：选完 2、5、10 级的卡后，每名角色换上不同颜色的衣服，逐步加上饰品和脚下印纹。走进松林、竹径、雨庭、雪岭和破晓地图时，还会分别披上月披、风披、雨披、绒领和晨光披肩；回到古道则换回基础外搭。换装不改变属性，联机双方按各自选完的卡计算。
- **武器进化**:武器升到满级且持有对应的被动道具后,升级选项里会出现金色的"进化"卡。

  | 武器 | 进化搭档 | 进化形态 |
  |------|----------|----------|
  | 星火弹 | 急速沙漏 | 星爆 |
  | 环绕萤火 | 广域透镜 | 永恒星环 |
  | 落雷 | 复制棱镜 | 雷暴 |
  | 荆棘光环 | 铁木护符 | 荆棘壁垒 |
  | 回旋飞刃 | 疾风靴 | 风暴之刃 |
  | 陨星 | 力量符石 | 天火 |
  | 霜环 | 晨露 | 凛冬 |
  | 光矛 | 引星磁石 | 引星矛 |
  | 鼠伴出击（开心专属） | 疾风靴 | 百鼠夜行 |
  | 灵猴踏枝（果果专属） | 广域透镜 | 群猴闹山 |
  | 代码连发（竹专属） | 急速沙漏 | 全量编译 |

- **百鬼夜行**：普通怪潮有长发寿衣鬼、飞得快的招魂纸鸢、成群的灯笼小鬼、厚重的镇墓石兽、远投碎面的画皮妖、穿障的黑无常，以及后段披旧铜甲的牛头阴差。敌人的种类、数量和血量随时间增长；每 45 秒出现一只精英（击杀掉宝箱），另有定时合围。
- **地图**：地貌、灯光、交互机关和怪潮各有配置。回到旧地图时，已经点亮的灯和使用过的机关不会重置。

  | 地图 | 地貌和天气 | 灯具和机关 | 常见敌人 / Boss |
  |---|---|---|---|
  | 松灯古道 | 暮色下的松树、山石、路碑 | 暖光石灯（受伤时可回血一次）；补给木匣 | 寿衣鬼、纸扎童子 |
  | 月下松林 | 松树、墓碑、供台与薄雾 | 青色幽冥灯；镇魂钟击退并减速 | 寿衣鬼、黑无常；4:00 夜魇 |
  | 风过竹径 | 竹林、竹篱、摆动的芦苇 | 纸灯笼；镇纸符只减速，不击退 | 黄符僵尸、纸扎童子、招魂纸鸢 |
  | 雨落石庭 | 庭门、照壁、铺地石和积水 | 红色喜灯；引星符阵吸经验 | 油纸伞鬼、鬼新娘；12:00 冥轿鬼后 |
  | 霜封山径 | 雪松、覆盖积雪的山石、飘雪 | 火盆；取暖龛最多回复 18% 生命且只能用一次 | 白无常、镇墓石兽、牛头阴差；8:00 棺山尸王 |
  | 天光破晓 | 晨光下的残碑与古道 | 金色晨灯；破晓香台在有敌人时提供一次短暂无敌 | 镇墓石兽、黑无常、牛头阴差 |

  - 转场时地面、灯光和天气淡变；中途切换地图碰撞，只移开被新障碍盖住的对象。已经在场的鬼怪不会被替换。天气不改变角色移速，投射物可以穿过障碍。
  - 走近即可点灯或触发机关。没点灯也能辨认道路和鬼怪轮廓；弹幕和 Boss 预警画在夜色上方。开启「减少动态效果」会隐藏天气粒子、飘雾与植物摆动。
- **Boss**：傩面夜魇沿红色通道冲锋；棺山尸王锁定地面并震出三个伤害圈；冥轿鬼后朝预警扇面撒出九张喜帖。交战中停留在 Boss 的地图；后一位按时加入队列，轮到它时才移入对应场地。
  - **守夜抉择**：每位 Boss 登场前暂停一次。可花本局金币布符削弱招式（夜魇冲锋变慢、尸王震圈缩小、鬼后少发喜帖），也可以主动强化同一招式，击败后领额外赏金。余额不足时仍能免费照常迎战；选择只影响这场战斗，不动局外钱包。
  - 击败任一 Boss 都会触发 **破晓余光**：战场照亮约 6 秒，自动收齐全图已有的经验宝石，并回复最多 25% 最大生命。Boss 宝箱仍在掉落地点，其他夜兽不会消失。
- **局外成长**：每局获得的金币可用来买角色、永久强化或新技能。主菜单点「局外成长 → 购买技能」。技能只需购买一次，刷新后仍解锁；不替换开局武器，也不带入双人局。购买后，所有角色在单人局可从升级卡或宝箱习得，第 2 级选卡会优先给一项已购且尚未习得的技能。
  - **追魂铜钱（90 金币）**：命中后弹向其他夜兽，初始可弹跳两次。
  - **安魂香炉（140 金币）**：附近有怪才在脚下布设，烟圈固定在原地，持续伤害并减速。
  - **照骨镜（190 金币）**：把下一发敌方弹幕原路弹回，反射之后才进入冷却；不防贴身伤害。
- **巡夜场景**：在「局外成长 → 巡夜场景」可永久购买开局路线。月下松林 **100**、雨落石庭 **140**、霜封山径 **160** 金币；松灯古道免费。前 1 分钟使用所选地图的天气、灯具、机关和怪群，随后转入竹径、接回同一夜巡路线，三位 Boss 的时刻与主场不变。默认路线仍会在 **2:57** 开始转入雪岭，不买也能玩到所有场景。
- **守夜印与英雄修炼**：正式单人每满 90 秒得 1 枚，每打倒一位 Boss 和守到黎明各加 2 枚，统一在结算时入账。到「局外成长 → 英雄修炼」给当前英雄升级基础生命（每级 +6）、伤害（每级 +3%）或移速（每级 +2%）。每项最多 3 级，依次耗 2、3、4 枚守夜印。只影响该英雄的单人开局，可与全局永久强化叠加；练习局和双人局不产出守夜印，双人也不带入修炼或已购开局路线。
- **守夜委托**：主菜单可选一项单人支线，不接也能照常开局。战斗右下角显示进度，完成后即使阵亡也会在结算时拿到额外奖励。每项只能领一次，练习局和双人局不发委托奖励；未完成的委托自动保留，可在下局重试。
  - **雨庭添灯**：点亮雨庭 3 盏不同喜灯，重访不会重置，奖励 60 金币和 1 枚守夜印。
  - **雪岭禁暖**：在雪岭连续坚持 30 秒；离开雪岭或用取暖龛回血会重新计时，奖励 75 金币和 1 枚守夜印。
  - **揭符破魇**：选「揭符悬赏」后击败强化夜魇，奖励 120 金币和 2 枚守夜印，另计正常悬赏奖励。
  - 地图委托还包括 **竹径镇纸**（两处不同镇纸符）、**松林暮钟**（一次震到 4 只夜兽）、**引星归灯**（一次引来 6 颗经验宝石）。
  - 战斗委托还包括 **精英夜猎**（击败 3 只精英）、**余光寻宝**（开一只 Boss 宝箱）、**三关破夜**（同一局击败三位不同 Boss）。可在委托面板按「地图／战斗」筛选。
- **小老鼠·开心**:默认解锁，移速 +8%、生命 -10。专属武器「鼠伴出击」会自动派小鼠追击夜兽，升到 6 级并持有疾风靴后可进化为「百鼠夜行」。头像保留照片参考里的黑色耳机、黄衫和双手比耶，不包含原照片。
  - 战斗时手持小手电，暖光照向最近的移动方向。灯光只影响画面，不参与战斗判定。
  - 开心升级时优先出现尚未习得的专属武器：**黏黏年糕**留下踩中才触发的范围减速陷阱，**冰淇淋旋风**用绕身甜筒伤害并减速敌人，**彩糖连发**朝附近敌人射出彩色糖果。
  - **西瓜炸弹**抛向夜兽，落地造成范围伤害；**篮球投射**命中后弹向附近不同的夜兽，升级可增加弹射次数。
  - **珍珠奶茶**命中后洒出一地珍珠，持续伤害并减速踩进来的夜兽；升级可扩大范围、延长持续时间。
  - **回血鸡腿**在生命低于 70% 时自动吃下，初始回复 16% 最大生命、冷却 12 秒；升满后回复 25%，基础冷却 9.5 秒。
- **小啾咪·果果**:默认解锁，攻击数量 +1、生命 -10。专属武器「灵猴踏枝」会派小猴跃向夜兽，落地造成范围伤害。升到 6 级并持有广域透镜后可进化为「群猴闹山」。保留原有的熊猫卫衣造型。
  - 果果升级时优先出现尚未习得的专属技能：**土豆滚滚**朝移动方向滚出可贯穿并推开夜兽的土豆，**番茄飞溅**命中后留下持续伤害的番茄酱。
  - 保命技能 **芒果干补给** 在生命低于 85% 时自动回血；**试卷护盾** 挡住伤害并减速附近夜兽，升级后最多可储存两张试卷。
- **川妹·霄霄**：默认解锁，生命 +10、护甲 +1。开局用 **香辣连发** 投出辣条，升级可选 **万马奔腾** 召唤冲锋小马、**妈妈怒吼** 震退周围夜兽、**水润护肤** 回血并短时间减伤。改名不影响旧档选择和技能。选人头像保留照片中的中分长发、羽绒服、红围巾和举手姿势，不包含原照片。
  - **黄金砸怪**会召来金元宝，落地时伤害并震退附近夜兽；升到 5 级可同时砸下两个元宝。
- **工程师·竹**：默认解锁，武器冷却缩短 6%，初始生命 95。保留短发、细框眼镜和立领工装，不内置原照。绑带和侧扣把头灯固定在额前，灯壳架在独立支座上；光束随面向转动，只影响画面。
  - 初始技能 **代码连发**自动瞄准最近夜兽；满级搭配急速沙漏可进化成 **全量编译**，分打多个目标并在命中时造成溅射。
  - **登机快线**沿最近的移动方向飞出可穿怪的登机牌，适合边走位边清一条线；**长面牵绊**在夜兽靠近时甩出面条圈，伤害并减速近处的怪。
  - **AI 预判拦截**在本地估算敌人的短期走向，先用雷达标出预计最密集的落点，再打范围伤害。不联网，也不需要账号。
- **系统角色剪影**：艾拉戴斗笠提灯，布隆穿宽肩铁匠围裙扛锤，诺瓦高冠持星杖，塞恩穿短猎装、手持弯刃；原属性、武器和解锁条件不变。

## 代码结构

```
survivor-game/
├── index.html        # 页面结构、脚本加载顺序
├── css/              # 基础样式、页面组件、响应式规则
├── art/              # 山水封面与灯笼印章
├── js/
│   ├── app/          # 浏览器入口、输入、战斗事件转接
│   ├── ui/           # 名册、商店、战斗弹层、HUD
│   ├── battle/
│   │   ├── battle.js # 回合状态和每帧更新顺序
│   │   ├── world/    # 地形、天气与场景切换；interactions.js 管场景机关
│   │   ├── characters/ # 角色数据、装备成长和升级
│   │   ├── enemies/  # 鬼怪资料、刷怪、移动与攻击
│   │   └── combat/   # 武器、投射物、命中、掉落和战斗效果
│   ├── render/       # Canvas 渲染，按场景、角色、鬼怪和战斗效果分组
│   ├── audio/        # 配乐、音效和混音
│   ├── net/          # 局域网信令、传输和战场快照
│   ├── platform/     # 本地存档
│   └── shared/       # 数学函数
└── tests/            # Node 自带测试运行器，无额外依赖
```

`createBattle({ save, emit, play })` 不依赖浏览器。每帧传入移动向量，升级、宝箱、结算和提示通过事件交给 `js/app/main.js`，由它通知界面。渲染读取战斗状态，不改变敌人的更新顺序。
`index.html` 使用经典脚本以支持直接打开文件；测试复用其中的脚本顺序。在项目目录运行 `node --test` 可验证层级边界、玩法和存档兼容。
